# Лабораторная работа № 11 — HTTP-сервис 1С

Практическая реализация задания «Привет, мир!» и индивидуального задания в
1С:Предприятии. Методичка описывает вариант на Node.js; здесь та же логика
выполнена через HTTP-сервис 1С и Apache 2.2.

## Ветка `main`

Базовая версия сервиса возвращает HTML-страницу с надписью «Привет, мир!».
Исходный модуль: [`src/HelloServiceModule.bsl`](src/HelloServiceModule.bsl).

## Что использовано

- 1С:Предприятие 8.3 (учебная версия);
- HTTP-сервис `HelloService`;
- шаблон URL `Root`, метод `GET`;
- Apache 2.2 с модулем веб-расширения 1С `wsap22t.dll`.

Индивидуальная информация и вычисление π находятся в ветке
`feature/student-info`, подготовленной для Pull Request.
