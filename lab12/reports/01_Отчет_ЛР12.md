## Цель работы

Реализовать учебную адаптацию событийной модели Node.js в 1С:Предприятии: HTTP-сервис, диспетчер событий, журналирование, очередь отложенных задач и демонстрацию порядка выполнения задач.

## Состав решения

- HTTP-сервис `Lab12` с маршрутами `/`, `/start`, `/stop`, `/order/{id}`, `/event-loop` и `/user-action`;
- общие модули `СобытияСервера`, `Логгер`, `ОбработчикЗаказов`, `EventLoopDemo`;
- регистр сведений `ОчередьСобытий`;
- регламентное задание `ОбработкаОчередиСобытий`.

## Проверенные маршруты

| Маршрут | Результат |
| --- | --- |
| `/hs/lab12/` | `Hello from Event-Driven Server!` |
| `/hs/lab12/start` | `Event server started` |
| `/hs/lab12/stop` | `Event server stopped` |
| `/hs/lab12/order/1` | `Заказ #1 принят в обработку` |
| `/hs/lab12/event-loop` | `Демонстрация Event Loop выполнена` |
| `/hs/lab12/user-action?userId=42&action=login` | `user:action обработан` |

## Логика очереди

При запросе `/order/1` обработчик создаёт две записи регистра: `order:processing` через 2 секунды и `order:complete` через 4 секунды. Регламентное задание вызывает `ОбработчикЗаказов.ОбработатьОчередь()`, обрабатывает готовые записи и устанавливает им статус `Выполнено`.
